  <project_name>Keyframe Razor</project_name>

  <overview>
    Keyframe Razor is a performant, cache-utilizing Progressive Web App (PWA) designed as a video editing application that runs entirely in the browser. The app enables users to edit videos with the ability to output video with audio, audio-only, or video-only exports. Its core innovation includes intelligent filler word detection and prolonged silence detection systems that are toggleable and automatically remove those sections for an improved viewing experience. The application is built to work offline and leverages modern browser technologies including IndexedDB and Web APIs for client-side video processing, ensuring performance-friendly operations without server-side dependencies.
  </overview>
